# الاستخدام · Usage

## العربي

### الشاشة الرئيسية (من فوق لتحت)
- **الشريط العلوي:** الساعة والتاريخ، الطقس (حسب مدينتك من الـIP)، آخر تطبيق فتحته، وزر الترس (لوحة الإعدادات السريعة).
- **بطاقة المباراة:** المباراة القادمة لكل فريق في `TEAMS` (حالياً برشلونة، الريال، الهلال، النصر). عدّاد `HH:MM:SS` (أو «يومان و HH:MM:SS»)، ولو جارية تعرض النتيجة والدقيقة.
- **تطبيقاتك:** التطبيقات المحمّلة. أي تطبيق جديد تنزّله يظهر بعد العودة للواجهة (أو خلال 30 ثانية).
- **المدخلات والنظام:** HDMI بشعاراتها، وتطبيقات النظام الأساسية (إعدادات، متصفح، وسائط، متجر، Homebrew).
- **أسفل الشاشة:** شعار «الجلسة» وشعارات الأندية (زينة، ما تتحدد).

### الريموت
| الضغط | يعمل |
|---|---|
| الأسهم | تنقل بين العناصر |
| **OK** (قصير) | فتح التطبيق / المدخل |
| **OK مطوّل** (نصف ثانية) على تطبيق أو مدخل | قائمة: **نقل** (بالأسهم يمين/يسار ثم OK أو رجوع للتثبيت)، **إخفاء**، **حذف** (للتطبيقات المحمّلة فقط، يطلب تأكيد، ويحذف من التلفزيون فعلاً) |
| على بطاقة المباراة: يمين/يسار | يبدّل بين مباريات الفرق |
| على بطاقة المباراة: **OK** | قائمة المباريات مع زر **تحديث الآن** (احتياط للتحديث الساعي) |
| **رجوع** | يغلق القائمة/اللوحة. من الهوم يرجع لما قبل |
| **Home** | يرجع للواجهة (ولو كنت بتطبيق ثاني) |
| المؤشر (Magic Remote) | المرور يحدد، النقر يفتح، الضغط المطوّل يفتح قائمة النقل/الإخفاء/الحذف، العجلة تنقل بين الصفوف |

### لوحة الترس
شاشة التوقف الآن · الشبكة · البلوتوث · مخرج الصوت · **صوت التنقل** (تشغيل/إطفاء) · **إظهار المخفية** · **تحديث المباريات** · **وضع الصورة** (يظهر لو الخدمة شغّالة؛ يبدّل بين قياسي، حيوي، اقتصادي، سينما، رياضة، ألعاب) · **إطفاء الشاشة** (الصوت يستمر) · **تنبيهات الأهداف** (تشغيل/إيقاف + بطاقة تجربة) · **تنظيف الذاكرة** · الصوت (+/−).
الشبكة والبلوتوث ومخرج الصوت تفتح لوحة إعدادات LG.

### شاشة التوقف
بعد `SAVER_MINUTES` (3 دقائق) بدون أي ضغطة والواجهة مفتوحة. أي زر أو حركة مؤشر ترجعك. تخف بالليل (11م–5ص) وتتحرك الكتلة ببطء. تشتغل **فقط والواجهة هي المعروضة**.

### التنبيهات
تنبيهات دوري أبطال أوروبا تظهر لحالها فوق أي تطبيق، حتى فوق Netflix. التفاصيل: [ALERTS.md](ALERTS.md).

## English

### The home screen (top to bottom)
- **Top bar:** clock and date, weather (city found from your IP), the last app you opened, and the gear button (quick settings).
- **Match card:** the next match of each team in `TEAMS` (currently Barcelona, Real Madrid, Al Hilal, Al Nassr). An `HH:MM:SS` countdown (or "2 days and HH:MM:SS"); when live it shows the score and minute.
- **Your apps:** downloaded apps. A newly installed app shows up when you return to the home (or within 30 s).
- **Inputs and System:** HDMI inputs with their logos, and the essential system apps (Settings, Browser, Media, Store, Homebrew).
- **Bottom:** the "Aljalsa" mark and club crests (decoration, not selectable).

### Remote control
| Press | Does |
|---|---|
| Arrows | move between items |
| **OK** (short) | open the app / input |
| **OK held** (0.5 s) on an app or input | menu: **Move** (arrows left/right, then OK or Back to drop), **Hide**, **Delete** (downloaded apps only, asks to confirm, really uninstalls) |
| On the match card: left/right | switch between the teams' matches |
| On the match card: **OK** | match list with a **Refresh now** button (backup for the hourly refresh) |
| **Back** | closes a menu/panel |
| **Home** | returns to the home screen (even from another app) |
| Magic Remote pointer | hover selects, click opens, press-and-hold opens the move/hide/delete menu, wheel moves between rows |

### Gear panel
Screensaver now · Network · Bluetooth · Sound output · **Navigation sound** (on/off) · **Show hidden items** · **Refresh matches** · **Picture mode** (shown when the service runs; cycles Standard, Vivid, Eco, Cinema, Sports, Game) · **Screen off** (audio keeps playing) · **Goal alerts** (on/off + a test card) · **Clean memory** · Volume (+/−).
Network, Bluetooth and Sound output open LG's own settings panel.

### Screensaver
Starts after `SAVER_MINUTES` (3 min) without any key while the home is open. Any key or pointer movement dismisses it. It dims at night (11 pm–5 am) and the block drifts slowly. It runs **only while the home screen is showing**.

### Alerts
Champions League alerts appear by themselves over any app, even Netflix. Details: [ALERTS.md](ALERTS.md).
